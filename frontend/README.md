# PaperCraft Frontend
 
React SPA frontend for PaperCraft. Built with React 18, Vite, TypeScript, and TailwindCSS.
 
## Quick Start
 
```bash
cd frontend
npm install
npm run dev
```
 
Open [http://localhost:5173](http://localhost:5173) in your browser.
 
## Environment Configuration (`.env`)
 
```env
VITE_API_BASE_URL=http://localhost:8000
VITE_SUPABASE_URL=https://your-supabase-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```
 
## Commands
 
| Command | Action |
| :--- | :--- |
| `npm run dev` | Starts the Vite dev server with hot module replacement |
| `npm run build` | Runs TypeScript typecheck and builds the production bundle |
| `npm run preview`| Locally previews the production build |
| `npm run lint` | Runs ESLint checks across TypeScript and React source files |
